Instrucciones de Vinculación

  • Paso 1: Abrir WhatsApp Abra la aplicación de WhatsApp en su teléfono móvil personal.
  • Paso 2: Dispositivos Vinculados Vaya a Configuración (iOS) o Menú (Android) → Dispositivos vinculados → Vincular un dispositivo.
  • Paso 3: Escanear Código QR Apunte la cámara de su teléfono hacia la pantalla para escanear el código QR que se muestra a la derecha.

Recomendaciones:

Mantenga su teléfono conectado a Internet para una sincronización óptima.
El código QR se actualiza dinámicamente si expira para garantizar la seguridad.
Una vez vinculado, el bot responderá chats de forma inmediata incluso si cierra esta página.
